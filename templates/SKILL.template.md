# Nama Skill Kamu

## Overview

Jelaskan secara singkat skill ini untuk apa, siapa yang cocok memakai, dan hasil akhirnya apa.

## When to Use

Pakai skill ini saat:

- user meminta ...
- agent perlu ...
- workflow membutuhkan ...

Jangan pakai skill ini saat:

- tugasnya terlalu sederhana dan tidak butuh prosedur khusus,
- tugasnya membutuhkan credential/akses yang belum tersedia,
- risiko keamanan belum jelas.

## Prasyarat

- Tool/CLI yang dibutuhkan: `...`
- Environment variable yang dibutuhkan: `...`
- Akun/API yang dibutuhkan: `...`

Kalau tidak ada prasyarat, tulis: `Tidak ada prasyarat khusus.`

## Langkah Kerja

1. Pahami tujuan user dan batasan tugas.
2. Cek prasyarat yang dibutuhkan.
3. Jalankan workflow utama.
4. Verifikasi hasil dengan command atau output nyata.
5. Laporkan hasil secara singkat dalam bahasa Indonesia.

```bash
# contoh command
hermes skills list
```

## Common Pitfalls

1. **Masalah umum pertama.** Solusi: ...
2. **Masalah umum kedua.** Solusi: ...

## Verification Checklist

- [ ] Prasyarat sudah dicek.
- [ ] Langkah utama selesai.
- [ ] Output diverifikasi dengan command/tool nyata.
- [ ] Tidak ada credential atau data sensitif tersimpan.
- [ ] Jawaban akhir ringkas dan mudah dipahami.
